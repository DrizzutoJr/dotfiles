# Dotfiles

Terms for configuration this repository distributes across the owner's macOS devices.

## Language

**Managed agent configuration**:
Agent instructions or settings authored in this repository and linked into a user's home configuration.

**Declared plugin**:
A third-party agent plugin identified in this repository for installation into each user's agent environment; the installed plugin files remain outside the repository.

**Legacy AI configuration**:
Previously tracked agent configuration kept for selective migration into the new setup.
